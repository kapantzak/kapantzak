Senior frontend engineer at [Netdata](https://www.netdata.cloud/), based in Thessaloniki, Greece. I build things for the web, and these days I mostly work with React and AI agents.

## What I'm working on

- The frontend of Netdata Cloud, a large React application for infrastructure monitoring and observability
- AI features in the product: a conversational assistant with streaming responses, Model Context Protocol (MCP) support, and AI-generated investigation reports
- Netdata's open-source frontend libraries: [netdata-ui](https://github.com/netdata/netdata-ui), the UI component kit, and [charts](https://github.com/netdata/charts), the charting SDK
